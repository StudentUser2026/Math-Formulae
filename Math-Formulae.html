Algebra

Identities

  • (𝑎+𝑏)2 = 𝑎2 + 2𝑎𝑏 + 𝑏2
  • (𝑎−𝑏)2 = 𝑎2 − 2𝑎𝑏 + 𝑏2
  • a² - b² = (a + b)(a - b)
  • (a + b)³ = a³ + 3a²b + 3ab² + b³
  • (a - b)³ = a³ - 3a²b + 3ab² - b³
  • a³ + b³ = (a + b)(a² - ab + b²)
  • a³ - b³ = (a - b)(a² + ab + b²)
